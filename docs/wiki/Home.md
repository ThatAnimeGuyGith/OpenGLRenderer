# OpenGL Renderer

OpenGL Renderer is a C++20 learning project built on OpenGL 3.3, GLFW, glad, nlohmann/json, and tinyobjloader. It loads a triangulated Wavefront OBJ mesh, applies a small fixed diffuse-lighting shader, and draws it in a rotating window.
